📌 Project Overview

This project analyzes Olist sales data using Excel to uncover key business insights. The analysis focuses on sales performance, order volume, customer distribution, product categories, and delivery performance to support better business decision-making.

🎯 Objective

To analyze Olist sales data and identify sales trends, top-performing customer states, high-selling product categories, and delivery performance.

🛠️ Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Excel Formulas
* Data Cleaning Techniques

📊 Key Features

* Interactive dashboard using Pivot Tables and Pivot Charts
* Dynamic KPI cards for Total Sales, Total Orders, Total Customers, and Average Order Value
* Sales analysis by month and year
* Delivery status analysis using a donut chart
* Top 10 customer states by sales
* Top 10 product categories by sales
* Interactive filtering using Order Year and Customer State slicers

🔍 Key Insights

* Sales performance varies across different months and years
* A small number of customer states contribute significantly to overall sales
* Certain product categories generate much higher sales than others
* Most orders are delivered on time, while a smaller proportion are late or not delivered
* Customer and order performance can be analyzed dynamically using slicers

📁 Project Files

* Excel File (`Olist Sales Dashboard.xlsx`)
* Dashboard Screenshot
* Pivot Tables and Processed Data Sheets
